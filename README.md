# Boo - Your Personal Task Organizer

A cute, simple, and aesthetic Progressive Web App (PWA) designed to help you manage daily tasks, build good habits, and stay motivated. The application leverages browser storage for local state management and integrates with Google Workspace APIs for external calendar synchronization.

## Core Features
* Task Management: CRUD operations for daily tasks utilizing the Web Storage API for local data persistence.
* Google Calendar Integration: OAuth 2.0 authenticated integration with the Google Calendar API to synchronize tasks and dispatch event invitations via Gmail.
* Habit Tracking System: Structured UI components designed for monitoring and logging daily routines.
* Gamification Interface: Interactive DOM elements ("Aura Jar") designed to enhance user engagement through daily micro-interactions.
* PWA Architecture: Configured with a web app manifest and service workers to support installability and native-like mobile experience.

## Technical Stack
* Frontend: HTML5, CSS3, Vanilla JavaScript
* APIs & Authentication: Google Calendar API, Google OAuth 2.0
* Architecture: Progressive Web App (PWA)
